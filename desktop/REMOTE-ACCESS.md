# اجرای ویندوز و دسترسی اختیاری موبایل

استفادهٔ اصلی: نصب‌کنندهٔ Setup-Windows-x64.exe را اجرا کنید. برنامه بدون نصب جداگانهٔ Node کنار ساعت اجرا می‌شود. گزینهٔ Start with Windows در منوی آیکون، شروع خودکار را برای همان کاربر فعال می‌کند. بستن مرورگر سرور را متوقف نمی‌کند؛ خواب یا خاموشی رایانه جمع‌آوری را متوقف می‌کند.

برنامه پیش‌فرض فقط روی 127.0.0.1 باز است. برای دسترسی از گوشی، یک مسیر HTTPS معتبر مانند reverse proxy یا Tailscale Serve روی رایانه لازم است؛ این بسته آن سرویس خارجی را نصب یا فعال نمی‌کند. از بازکردن مستقیم پورت برنامه روی اینترنت استفاده نکنید.

برای اجرای دستی پشت HTTPS، APP_PUBLIC_MODE=1، APP_ALLOWED_HOSTS برابر نام دقیق دامنه، و APP_ADMIN_PASSWORD_FILE برابر مسیر فایل خصوصی گذرواژهٔ حداقل ۱۶ نویسه را تنظیم کنید. HOST را 127.0.0.1 نگه دارید و پراکسی را به همان نشانی وصل کنید. گذرواژه را در Git یا چت قرار ندهید. ورود با کوکی HttpOnly و SameSite=Strict انجام می‌شود؛ در حالت عمومی کوکی Secure است. گوشی از همان نشانی HTTPS وارد می‌شود و می‌تواند وب‌برنامه را به صفحهٔ اصلی اضافه کند. تا زمان تنظیم مسیر HTTPS، دسترسی گوشی دیگری فعال نیست.

به‌روزرسانی: در «ویندوز و موبایل» بررسی یا دریافت نسخهٔ معتبر را بزنید؛ نصب از منوی کنار ساعت انجام می‌شود. حالت خودکار اختیاری است. امضای Ed25519 اطلاعیه و SHA-256 فایل پیش از اجرا بررسی می‌شوند و پیش از نصب پشتیبان گرفته می‌شود. نصب‌کننده گواهی Windows Authenticode ندارد؛ امضای انتشار، جایگزین گواهی ناشر ویندوز نیست.
