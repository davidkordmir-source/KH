# دیدبان — اتاق خبر شخصی

برنامهٔ وب فارسی و راست‌به‌چپ برای گردآوری خبر، پایش کلیدواژه‌ها و مدیریت منابع خبری و اتصال‌های شبکه‌های اجتماعی. خبرها از منبع اصلی دریافت می‌شوند؛ دادهٔ نمایشی یا خبر ساختگی در برنامه وجود ندارد.

## دانلود برنامه

**[دانلود دیدبان ۰٫۲٫۱ برای ویندوز ۶۴ بیتی — بدون نصب Node.js](https://github.com/davidkordmir-source/KH/raw/refs/tags/v0.2.1/downloads/Dideban-v0.2.1-Windows-x64.zip)**

[بررسی SHA-256 فایل](downloads/SHA256SUMS.txt)

در ویندوز ۱۰ یا ۱۱، ۶۴ بیتی، روی ZIP راست‌کلیک کنید و **Extract All** را بزنید. سپس در پوشهٔ استخراج‌شده `start-windows.cmd` را اجرا کنید. Node.js رسمی و وابستگی‌های آماده داخل این بسته هستند؛ نصب اولیه حذف شده و رابط در مرورگر باز می‌شود. پنجرهٔ اجرا را باز نگه دارید. دریافت خبرها به اینترنت نیاز دارد. راهنمای کوتاه داخل بسته، `DOWNLOAD-README-fa.txt` است. در صورت خطا، راه‌انداز مسیر گزارش خطا را نشان می‌دهد.

[نسخهٔ معمولی ZIP برای مک، لینوکس یا Node.js ازپیش‌نصب‌شده](https://github.com/davidkordmir-source/KH/raw/refs/tags/v0.2.1/downloads/Dideban-v0.2.1.zip): این نسخه به **Node.js 24 یا جدیدتر** نیاز دارد. پس از نصب Node از [سایت رسمی](https://nodejs.org/)، ZIP را کامل استخراج کنید و `sh start.sh` را در لینوکس/مک یا `start-windows.cmd` را در ویندوز اجرا کنید. نسخهٔ معمولی در اجرای اول وابستگی‌ها را از اینترنت نصب می‌کند.

برای ساخت دوبارهٔ بسته پس از تغییر کد، `npm run build` و سپس `python3 scripts/package_release.py` را اجرا کنید. بسته شامل رابط ساخته‌شده، سرور و راه‌انداز است؛ داده‌ها و اتصال‌های شخصی هنگام اجرای خودتان ایجاد می‌شوند.

برای بستهٔ ویندوز، ZIP رسمی Node.js 24 برای Windows x64 و فایل رسمی `SHASUMS256.txt` را از `nodejs.org` دریافت کنید. سپس `python3 scripts/package_windows.py --node-archive /path/to/node-v24.x.y-win-x64.zip --node-shasums /path/to/SHASUMS256.txt` را اجرا کنید. ابزار قبل از استفاده، SHA-256 زمان‌اجرای Node را بررسی و وابستگی‌ها را از lockfile نصب می‌کند؛ فایل منشأ و مجوز Node در بسته قرار می‌گیرند. بستهٔ ویندوز در محیط لینوکس ساخته و بررسی می‌شود؛ اجرای آن روی خود ویندوز نیاز به آزمون در ویندوز دارد.

## اجرا

نیازمندی: **Node.js 24 یا جدیدتر** و npm. پایگاه دادهٔ SQLite داخل Node است؛ نصب سرویس جداگانه لازم نیست.

```sh
cd /workspace/KH
npm ci --cache /tmp/dideban-npm-cache
npm run dev
```

Vite روی پورت ۵۱۷۳ و API روی پورت ۳۰۰۱ اجرا می‌شوند. برنامه به‌طور پیش‌فرض فقط روی دستگاه محلی در دسترس است. در رابط کاربری «به‌روزرسانی» را بزنید تا منابع فعال دریافت شوند. دریافت زمان‌بندی‌شده نیز در سرور انجام می‌شود.

برای اجرای نسخهٔ ساخته‌شده:

```sh
npm run build
npm start
```

در این حالت سرور API، فایل‌های وب را هم روی پورت ۳۰۰۱ ارائه می‌کند. این نسخه برای استفادهٔ شخصی در محیط خصوصی است؛ انتشار عمومی نیاز به احراز هویت کاربر، HTTPS، مدیریت نشست و محدودسازی درخواست‌ها دارد.

## امکانات

- گردآوری RSS و Atom از BBC فارسی، BBC World، Guardian و Al Jazeera و افزودن منابع دلخواه.
- داشبورد با جست‌وجو، دسته‌بندی موضوعی، فیلتر زبان و منبع، بازهٔ ۲۴ ساعت یا هفت روز، ترتیب زمانی و ارتباط با کلیدواژه‌ها.
- ذخیرهٔ خبرهای منتخب، نمایش منبع و پیوند به مطلب اصلی.
- نگهداری منابع، کلیدواژه‌ها، اتصال‌ها و خبرها در SQLite بین راه‌اندازی‌ها.
- حذف موارد تکراری بر اساس نشانی، حذف پارامترهای رایج رهگیری و نمایش خطای هر منبع.
- اتصال به API رسمی پلتفرم‌ها با توکن و شناسه‌ای که خودتان در فرم اتصال وارد می‌کنید.

برای افزودن منبع می‌توانید نشانی فید RSS یا Atom یا صفحه‌ای را وارد کنید که فیدش را در HTML معرفی می‌کند؛ برنامه فید معرفی‌شده را پیدا و بررسی می‌کند. همهٔ سایت‌ها فید یا API عمومی ندارند. دسته‌بندی خبر با قواعد کلیدواژه‌ای انجام می‌شود و تشخیص قطعی صحت، اصالت یا «دست اول» بودن خبر نیست. متن کامل، ترجمه و خلاصه‌سازی با مدل هوش مصنوعی در این نسخه وجود ندارد.

## محدودهٔ اتصال حساب‌ها

| پلتفرم | دسترسی قابل استفاده | پیش‌نیاز |
| --- | --- | --- |
| تلگرام | پیام‌های تازهٔ ربات در کانال‌ها و گروه‌های در دسترسش | توکن BotFather و افزودن ربات با دسترسی لازم؛ بدون خواندن تاریخچه یا حساب شخصی |
| X / توییتر | جست‌وجوی اخیر بر اساس کلیدواژه‌ها و هشتگ‌ها | Bearer Token و طرح API دارای دسترسی recent search؛ ممکن است پولی باشد |
| اینستاگرام | رسانه‌های حساب حرفه‌ای و جست‌وجوی هشتگ در محدودهٔ API | Meta App، توکن دارای مجوز لازم و شناسهٔ حساب حرفه‌ای |
| فیسبوک | پست‌های صفحهٔ مجاز | Page Access Token، شناسهٔ Page و مجوز خواندن محتوای صفحه |
| لینکدین | پست‌های سازمان مجاز | دسترسی تأییدشدهٔ Community Management، توکن و شناسهٔ سازمان |

ورود با رمز عبور حساب‌ها پیاده‌سازی نشده است. توکن باید از مسیر رسمی همان پلتفرم صادر شود. OAuth تعاملیِ ثبت‌شده برای یک محصول عمومی، اتصال به تمام صفحه‌ها، فید شخصی نامحدود و پلتفرم‌های دیگر از مسیر اتصال سفارشی یا فید عمومی پشتیبانی می‌شوند؛ همهٔ شبکه‌ها API قابل استفاده ندارند. برنامه فقط پس از پاسخ موفق API اتصال را ثبت می‌کند. انقضای توکن، سهمیه، طرح پولی، بررسی برنامه و دسترسی محتوا همچنان تابع پلتفرم مربوط است.

کلیدواژه‌های رابط برای فیلتر و اولویت‌بندی خبرها و برای جست‌وجوی X و هشتگ اینستاگرام به کار می‌روند. هشتگ‌های اینستاگرام طبق محدودیت API به تعداد محدودی در هر دریافت بررسی می‌شوند. در تلگرام، رباتی که وبهوک فعال دارد باید ابتدا از مسیر رسمی برای polling آماده شود؛ برنامه وبهوک را خودکار حذف نمی‌کند.

## داده و امنیت

پوشهٔ `.data/` شامل SQLite و کلید محلی رمزنگاری است و در Git ثبت نمی‌شود. توکن‌ها در پایگاه داده با AES-256-GCM رمز می‌شوند و API آن‌ها را به مرورگر برنمی‌گرداند. این رمزنگاری جایگزین محافظت از دستگاه و نسخهٔ پشتیبان نیست: برای بازیابی، **پایگاه داده و کلید را با هم** به‌صورت امن نگه دارید. توکن‌ها را در کد، چت یا فایل‌های ثبت‌شده در Git قرار ندهید.

دریافت منابع فقط با HTTPS عمومی، اعتبارسنجی TLS، بررسی نشانی‌های خصوصی، محدودیت حجم و مهلت پاسخ انجام می‌شود. در محیط دارای HTTPS proxy، جلوگیری نهایی از تغییر DNS به IP خصوصی در سمت پراکسی باید توسط همان پراکسی تضمین شود. منابع RSS فقط به‌عنوان متن نمایش داده می‌شوند. حذف اتصال، دریافت بعدی از آن را متوقف می‌کند؛ خبرهای قبلی در آرشیو باقی می‌مانند.

## شبکهٔ محیط ابری

برای منابع پیش‌فرض، دامنه‌های `feeds.bbci.co.uk`، `www.theguardian.com` و `www.aljazeera.com` باید در تنظیمات شبکه مجاز باشند. برای اتصال‌های اجتماعی، `api.telegram.org`، `api.x.com`، `api.twitter.com`، `graph.facebook.com` و `api.linkedin.com` لازم‌اند. منبع سفارشی ممکن است به افزودن دامنهٔ خودش و مقصد تغییر مسیرش نیاز داشته باشد. تصویرهای خبر در مرورگر از میزبان منبع، از جمله `ichef.bbci.co.uk` و `i.guim.co.uk` بارگیری می‌شوند؛ نبودن تصویر مانع خواندن خبر نیست.

اگر DNS محلی محیط محدود باشد، فقط نام‌های ثابت ناشران پیش‌فرض و APIهای رسمی از مسیر پراکسی قابل حل هستند. منابع سفارشی همچنان باید از بررسی DNS عمومی عبور کنند؛ برنامه این بررسی را برای نشانی‌های دلخواه کنار نمی‌گذارد. خبر بدون تاریخ انتشار معتبر با برچسب «زمان انتشار نامشخص» نمایش داده می‌شود و در شمارش خبرهای امروز و فیلترهای زمانی قرار نمی‌گیرد.

ذخیرهٔ پیش‌نویس تنظیمات به‌تنهایی دسترسی شبکهٔ ماشین جاری را تغییر نمی‌دهد. اگر پراکسی پاسخ ۴۰۳ داد، تنظیمات محیط را ذخیره و اعمال کنید و دریافت را دوباره امتحان کنید.

## بررسی

```sh
npm test
npm run build
npm run test:e2e
```

آزمون‌های اتصال به شبکه‌های اجتماعی از پاسخ‌های شبیه‌سازی‌شدهٔ API استفاده می‌کنند؛ موفقیت آن‌ها تأیید دسترسی یک حساب واقعی نیست. تست مرورگر از Chromium سیستم در صورت وجود استفاده می‌کند؛ در دستگاه دیگر می‌توانید `npx playwright install chromium` را اجرا کنید. داده‌های آزمایشی از داده‌های واقعی برنامه جدا هستند.

تنظیمات اختیاری را در `.env` قرار دهید؛ نمونهٔ بدون اطلاعات محرمانه در `.env.example` است. با `AUTO_SYNC=0` دریافت زمان‌بندی‌شده متوقف می‌شود. برای تغییر پورت API باید مقصد پراکسی در `vite.config.ts` هم هماهنگ شود. تغییر `HOST` برای انتشار بیرونی به‌تنهایی احراز هویت ایجاد نمی‌کند.

پیش از ارتقا پنجرهٔ نسخهٔ قدیمی را ببندید. داده‌های ویندوز در همان LOCALAPPDATA/Dideban/data باقی می‌مانند. پیش از مهاجرت پایگاه قدیمی، نسخهٔ پشتیبان `news.pre-v2.sqlite` در پوشهٔ داده ساخته می‌شود؛ کلید رمزنگاری حفظ می‌شود. خبرهای حذف‌شده توسط نسخه‌های قبلی قابل بازسازی خودکار نیستند.

پشته: React، TypeScript، Vite، Express، SQLite داخلی Node و قلم Vazirmatn که همراه برنامه ارائه می‌شود.

نسخهٔ ۰٫۲٫۱: اصلاح کش صفحه پس از ارتقا، جلوگیری از برگرداندن HTML به جای فایل جاوااسکریپت ناموجود، تحمل مسدود بودن تنظیمات مرورگر و نمایش صفحهٔ بازیابی هنگام خطای رابط. اگر صفحه سفید شد Ctrl+F5 بزنید؛ نسخهٔ جدید را در پوشهٔ تازه Extract All و با start-windows.cmd اجرا کنید.
