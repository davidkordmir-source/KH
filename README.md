# دیدبان — اتاق خبر شخصی

برنامهٔ وب فارسی و راست‌به‌چپ برای گردآوری خبر، پایش کلیدواژه‌ها و مدیریت منابع خبری و اتصال‌های شبکه‌های اجتماعی. خبرها از منبع اصلی دریافت می‌شوند؛ دادهٔ نمایشی یا خبر ساختگی در برنامه وجود ندارد.

## دانلود برنامه

**[دانلود نصب‌کنندهٔ دیدبان ۰٫۶٫۰ برای ویندوز ۶۴ بیتی](https://github.com/davidkordmir-source/KH/raw/refs/tags/v0.6.0/downloads/Dideban-v0.6.0-Setup-Windows-x64.exe)**

برای اجرای مستقل، نصب‌کننده را اجرا و از میانبر دیدبان استفاده کنید. [بستهٔ قابل حمل ZIP](https://github.com/davidkordmir-source/KH/raw/refs/tags/v0.6.0/downloads/Dideban-v0.6.0-Windows-x64.zip) نیز در دسترس است.

[بررسی SHA-256 فایل](downloads/SHA256SUMS.txt)

در ویندوز ۱۰ یا ۱۱، ۶۴ بیتی، روی ZIP راست‌کلیک کنید و **Extract All** را بزنید. سپس در پوشهٔ استخراج‌شده `start-windows.cmd` را اجرا کنید. Node.js رسمی و وابستگی‌های آماده داخل این بسته هستند؛ نصب اولیه حذف شده و رابط در مرورگر باز می‌شود. پنجرهٔ اجرا را باز نگه دارید. دریافت خبرها به اینترنت نیاز دارد. راهنمای کوتاه داخل بسته، `DOWNLOAD-README-fa.txt` است. در صورت خطا، راه‌انداز مسیر گزارش خطا را نشان می‌دهد.

[نسخهٔ معمولی ZIP برای مک، لینوکس یا Node.js ازپیش‌نصب‌شده](https://github.com/davidkordmir-source/KH/raw/refs/tags/v0.6.0/downloads/Dideban-v0.6.0.zip): این نسخه به **Node.js 24 یا جدیدتر** نیاز دارد. پس از نصب Node از [سایت رسمی](https://nodejs.org/)، ZIP را کامل استخراج کنید و `sh start.sh` را در لینوکس/مک یا `start-windows.cmd` را در ویندوز اجرا کنید. نسخهٔ معمولی در اجرای اول وابستگی‌ها را از اینترنت نصب می‌کند.

برای ساخت دوبارهٔ بسته پس از تغییر کد، `npm run build` و سپس `python3 scripts/package_release.py` را اجرا کنید. بسته شامل رابط ساخته‌شده، سرور و راه‌انداز است؛ داده‌ها و اتصال‌های شخصی هنگام اجرای خودتان ایجاد می‌شوند.

برای بستهٔ ویندوز، ZIP رسمی Node.js 24 برای Windows x64 و فایل رسمی `SHASUMS256.txt` را از `nodejs.org` دریافت کنید. سپس `python3 scripts/package_windows.py --node-archive /path/to/node-v24.x.y-win-x64.zip --node-shasums /path/to/SHASUMS256.txt` را اجرا کنید. ابزار قبل از استفاده، SHA-256 زمان‌اجرای Node را بررسی و وابستگی‌ها را از lockfile نصب می‌کند؛ فایل منشأ و مجوز Node در بسته قرار می‌گیرند. بستهٔ ویندوز در محیط لینوکس ساخته و بررسی می‌شود؛ اجرای آن روی خود ویندوز نیاز به آزمون در ویندوز دارد.

## اجرا

نیازمندی: **Node.js 24 یا جدیدتر** و npm. پایگاه دادهٔ SQLite داخل Node است؛ نصب سرویس جداگانه لازم نیست.

```sh
cd /workspace/KH
npm ci --cache /tmp/dideban-npm-cache
npm run dev
```

Vite روی پورت ۵۱۷۳ و API روی پورت ۳۰۰۱ اجرا می‌شوند. برنامه به‌طور پیش‌فرض فقط روی دستگاه محلی در دسترس است. در رابط کاربری «به‌روزرسانی» را بزنید تا منابع فعال دریافت شوند. دریافت زمان‌بندی‌شده نیز در سرور انجام می‌شود.

برای اجرای نسخهٔ ساخته‌شده:

```sh
npm run build
npm start
```

در این حالت سرور API، فایل‌های وب را هم روی پورت ۳۰۰۱ ارائه می‌کند. این نسخه برای استفادهٔ شخصی در محیط خصوصی است؛ انتشار عمومی نیاز به احراز هویت کاربر، HTTPS، مدیریت نشست و محدودسازی درخواست‌ها دارد.

## امکانات

- گردآوری RSS و Atom از BBC فارسی، BBC World، Guardian و Al Jazeera و افزودن منابع دلخواه.
- داشبورد با جست‌وجو، دسته‌بندی موضوعی، فیلتر زبان و منبع، بازهٔ ۲۴ ساعت یا هفت روز، ترتیب زمانی و ارتباط با کلیدواژه‌ها.
- ذخیرهٔ خبرهای منتخب، نمایش منبع و پیوند به مطلب اصلی.
- نگهداری منابع، کلیدواژه‌ها، اتصال‌ها و خبرها در SQLite بین راه‌اندازی‌ها.
- حذف موارد تکراری بر اساس نشانی، حذف پارامترهای رایج رهگیری و نمایش خطای هر منبع.
- اتصال به API رسمی پلتفرم‌ها با توکن و شناسه‌ای که خودتان در فرم اتصال وارد می‌کنید.

برای افزودن منبع می‌توانید نشانی فید RSS یا Atom یا صفحه‌ای را وارد کنید که فیدش را در HTML معرفی می‌کند؛ برنامه فید معرفی‌شده را پیدا و بررسی می‌کند. همهٔ سایت‌ها فید یا API عمومی ندارند. دسته‌بندی خبر با قواعد کلیدواژه‌ای انجام می‌شود و تشخیص قطعی صحت، اصالت یا «دست اول» بودن خبر نیست. متن کامل، ترجمه و خلاصه‌سازی با مدل هوش مصنوعی در این نسخه وجود ندارد.

## محدودهٔ اتصال حساب‌ها

| پلتفرم | دسترسی قابل استفاده | پیش‌نیاز |
| --- | --- | --- |
| تلگرام | پیام‌های تازهٔ ربات در کانال‌ها و گروه‌های در دسترسش | توکن BotFather و افزودن ربات با دسترسی لازم؛ بدون خواندن تاریخچه یا حساب شخصی |
| X / توییتر | جست‌وجوی اخیر بر اساس کلیدواژه‌ها و هشتگ‌ها | Bearer Token و طرح API دارای دسترسی recent search؛ ممکن است پولی باشد |
| اینستاگرام | رسانه‌های حساب حرفه‌ای و جست‌وجوی هشتگ در محدودهٔ API | Meta App، توکن دارای مجوز لازم و شناسهٔ حساب حرفه‌ای |
| فیسبوک | پست‌های صفحهٔ مجاز | Page Access Token، شناسهٔ Page و مجوز خواندن محتوای صفحه |
| لینکدین | پست‌های سازمان مجاز | دسترسی تأییدشدهٔ Community Management، توکن و شناسهٔ سازمان |

ورود با رمز عبور حساب‌ها پیاده‌سازی نشده است. توکن باید از مسیر رسمی همان پلتفرم صادر شود. OAuth تعاملیِ ثبت‌شده برای یک محصول عمومی، اتصال به تمام صفحه‌ها، فید شخصی نامحدود و پلتفرم‌های دیگر از مسیر اتصال سفارشی یا فید عمومی پشتیبانی می‌شوند؛ همهٔ شبکه‌ها API قابل استفاده ندارند. برنامه فقط پس از پاسخ موفق API اتصال را ثبت می‌کند. انقضای توکن، سهمیه، طرح پولی، بررسی برنامه و دسترسی محتوا همچنان تابع پلتفرم مربوط است.

کلیدواژه‌های رابط برای فیلتر و اولویت‌بندی خبرها و برای جست‌وجوی X و هشتگ اینستاگرام به کار می‌روند. هشتگ‌های اینستاگرام طبق محدودیت API به تعداد محدودی در هر دریافت بررسی می‌شوند. در تلگرام، رباتی که وبهوک فعال دارد باید ابتدا از مسیر رسمی برای polling آماده شود؛ برنامه وبهوک را خودکار حذف نمی‌کند.

## داده و امنیت

پوشهٔ `.data/` شامل SQLite و کلید محلی رمزنگاری است و در Git ثبت نمی‌شود. توکن‌ها در پایگاه داده با AES-256-GCM رمز می‌شوند و API آن‌ها را به مرورگر برنمی‌گرداند. این رمزنگاری جایگزین محافظت از دستگاه و نسخهٔ پشتیبان نیست: برای بازیابی، **پایگاه داده و کلید را با هم** به‌صورت امن نگه دارید. توکن‌ها را در کد، چت یا فایل‌های ثبت‌شده در Git قرار ندهید.

دریافت منابع فقط با HTTPS عمومی، اعتبارسنجی TLS، بررسی نشانی‌های خصوصی، محدودیت حجم و مهلت پاسخ انجام می‌شود. در محیط دارای HTTPS proxy، جلوگیری نهایی از تغییر DNS به IP خصوصی در سمت پراکسی باید توسط همان پراکسی تضمین شود. منابع RSS فقط به‌عنوان متن نمایش داده می‌شوند. حذف اتصال، دریافت بعدی از آن را متوقف می‌کند؛ خبرهای قبلی در آرشیو باقی می‌مانند.

## شبکهٔ محیط ابری

برای منابع پیش‌فرض، دامنه‌های `feeds.bbci.co.uk`، `www.theguardian.com` و `www.aljazeera.com` باید در تنظیمات شبکه مجاز باشند. برای اتصال‌های اجتماعی، `api.telegram.org`، `api.x.com`، `api.twitter.com`، `graph.facebook.com` و `api.linkedin.com` لازم‌اند. منبع سفارشی ممکن است به افزودن دامنهٔ خودش و مقصد تغییر مسیرش نیاز داشته باشد. تصویرهای خبر در مرورگر از میزبان منبع، از جمله `ichef.bbci.co.uk` و `i.guim.co.uk` بارگیری می‌شوند؛ نبودن تصویر مانع خواندن خبر نیست.

اگر DNS محلی محیط محدود باشد، فقط نام‌های ثابت ناشران پیش‌فرض و APIهای رسمی از مسیر پراکسی قابل حل هستند. منابع سفارشی همچنان باید از بررسی DNS عمومی عبور کنند؛ برنامه این بررسی را برای نشانی‌های دلخواه کنار نمی‌گذارد. خبر بدون تاریخ انتشار معتبر با برچسب «زمان انتشار نامشخص» نمایش داده می‌شود و در شمارش خبرهای امروز و فیلترهای زمانی قرار نمی‌گیرد.

ذخیرهٔ پیش‌نویس تنظیمات به‌تنهایی دسترسی شبکهٔ ماشین جاری را تغییر نمی‌دهد. اگر پراکسی پاسخ ۴۰۳ داد، تنظیمات محیط را ذخیره و اعمال کنید و دریافت را دوباره امتحان کنید.

## بررسی

```sh
npm test
npm run build
npm run test:e2e
```

آزمون‌های اتصال به شبکه‌های اجتماعی از پاسخ‌های شبیه‌سازی‌شدهٔ API استفاده می‌کنند؛ موفقیت آن‌ها تأیید دسترسی یک حساب واقعی نیست. تست مرورگر از Chromium سیستم در صورت وجود استفاده می‌کند؛ در دستگاه دیگر می‌توانید `npx playwright install chromium` را اجرا کنید. داده‌های آزمایشی از داده‌های واقعی برنامه جدا هستند.

تنظیمات اختیاری را در `.env` قرار دهید؛ نمونهٔ بدون اطلاعات محرمانه در `.env.example` است. با `AUTO_SYNC=0` دریافت زمان‌بندی‌شده و بررسی خودکار هشدارها متوقف می‌شوند؛ دریافت و بررسی دستی همچنان در دسترس است. برای تغییر پورت API باید مقصد پراکسی در `vite.config.ts` هم هماهنگ شود. تغییر `HOST` برای انتشار بیرونی به‌تنهایی احراز هویت ایجاد نمی‌کند.

| به‌روزرسانی | بررسی نسخهٔ منتشرشده در گیت‌هاب و لینک دانلود ویندوز داخل برنامه؛ نصب با استخراج بستهٔ جدید و حفظ دادهٔ کاربر، بدون نصب خودکار |

پشتیبان قابل انتقال تا **۴۸ مگابایت پایگاه داده** را پشتیبانی می‌کند. برای آرشیو بزرگ‌تر، برنامه را ببندید و از کل پوشهٔ داده شامل `news.sqlite`، `credentials.key` و فایل‌های جانبی آن نسخهٔ امن بگیرید. پشتیبان محلی به کلید همان پوشه نیاز دارد؛ فایل `.dideban` با گذرواژه قابل انتقال به دستگاه دیگر است. گذرواژه نگه‌داری نمی‌شود و قابل بازیابی نیست.

بررسی و ثبت هشدارها به بازبودن برنامهٔ سرور نیاز دارد. اعلان سیستمی علاوه بر آن به بازبودن صفحهٔ مرورگر و مجوز Notifications نیاز دارد؛ اعلان خارج از مرورگر بسته‌شده یا ارسال پیام به پیام‌رسان در این نسخه پیاده‌سازی نشده است. برای ترجمه، دسترسی شبکه به `api.cognitive.microsofttranslator.com` لازم است. کلید قانونی سرویس را در خود برنامه وارد کنید؛ ثبت کلید به معنی تأیید موفق اتصال نیست و هنگام ترجمه پاسخ واقعی سرویس بررسی می‌شود.

در منابع رسمی، دکمه‌های آمریکا، بریتانیا، اسرائیل، روسیه و چین برای فیلتر سریع وجود دارند. لینک سایت رسمی با اتصال خودکار فرق دارد: موارد دارای «مشاهدهٔ سایت رسمی» فید فعال ندارند و به‌عنوان منبع متصل گزارش نمی‌شوند.

## ابزارهای نسخهٔ ۰٫۴٫۲

[دانلود نصب‌کنندهٔ ویندوز](https://github.com/davidkordmir-source/KH/raw/refs/tags/v0.6.0/downloads/Dideban-v0.6.0-Setup-Windows-x64.exe)؛ نصب برای کاربر فعلی، میانبر، اجرای کنار ساعت و شروع اختیاری با ویندوز. آرشیو قبلی در LOCALAPPDATA/Dideban/data حفظ می‌شود. پیش از ارتقای ساختار نسخهٔ ۰٫۳، news.pre-v4.sqlite ساخته می‌شود.

از «دستیار و ابزارهای تازه» به پرسش‌وپاسخ استخراجی از آرشیو، پاسخ هوشمند با نقل‌قول و لینک کنترل‌شده، نمایهٔ معنایی چندزبانه، گفتار و OCR و واردکردن SRT/VTT، پروندهٔ شرکت و نماد و گزارش SEC، نمودار مسیر انتشار و تنظیمات ویندوز دسترسی دارید. روی نمودارهای بازار، موضوع خبر را انتخاب کنید تا زمان انتشار خبرهای آرشیو روی محور زمانی واقعی علامت بخورد. همزمانی، اثبات علت حرکت قیمت نیست. تقویم اقتصادی تازه اضافه نشده است.

کلید رسمی OpenAI در تنظیم سرویس‌ها رمزگذاری می‌شود. مدل پیش‌فرض gpt-4.1-mini، گفتار whisper-1 و نمایه text-embedding-3-small با ۵۱۲ بُعد است. پاسخ استخراجی و واردکردن زیرنویس بدون کلید کار می‌کنند؛ قابلیت‌های API بدون کلید فعال نیستند. نمایه‌سازی در هر درخواست تا ۵۰ خبر از ۵۰۰ خبر اخیر با حداکثر ۶۰۰۰ نویسهٔ هر خبر را به سرویس می‌فرستد. پاسخ هوشمند حداکثر ۱۰ متن منتخب را می‌فرستد. صوت/ویدئو تا ۲۴ مگابایت و تصویر/PDF تا ۸ مگابایت؛ متن ماشینی ممکن است خطا داشته باشد. فایل اصلی رسانه نگه‌داری نمی‌شود؛ متن و زمان‌بندی محلی ذخیره می‌شود. نمودار استناد از پیوند واقعی فید، منبع اولیهٔ ثبت کاربر و جمله‌های مشترک ساخته می‌شود؛ منشأ قطعی بازنشر یا استقلال منابع را اثبات نمی‌کند.

نماد شرکت و CIK را خودتان ثبت کنید. قیمت Yahoo ممکن است با تأخیر باشد؛ SEC برای شرکت‌های دارای CIK و در صورت پاسخ سرویس نمایش داده می‌شود. SEC_CONTACT_EMAIL برای User-Agent مسئولانهٔ SEC قابل تنظیم است.

به‌روزرسانیِ نصب‌شده: اطلاعیهٔ Ed25519 و هش SHA-256 بررسی می‌شوند، نسخهٔ قدیمی‌تر پذیرفته نمی‌شود، پیش از نصب پشتیبان ساخته می‌شود. حالت خودکار از تنظیمات ویندوز اختیاری است و فقط در اجرای کنار ساعت کار می‌کند. برای انتشار نسخه‌های آینده مالک پروژه باید کلید خصوصی Ed25519 متناظر با desktop/update-public-key.pem را خصوصی نگه دارد و DIDEBAN_UPDATE_PRIVATE_KEY_FILE را برای scripts/sign_update.mjs تنظیم کند. کلید خصوصی در مخزن یا بسته‌ها نیست. امضای ناشر Windows Authenticode نیازمند گواهی صاحب پروژه است؛ این نصب‌کننده گواهی ناشر ویندوز ندارد.

بستهٔ ویندوز روی لینوکس ساخته می‌شود؛ اجرای مستقیم نصب‌کننده و PowerShell GUI در ویندوز در این محیط آزموده نشده است. ساخت نصب‌کننده: پس از package_windows.py، ابزار scripts/package_installer.py --makensis /path/to/makensis و سپس scripts/sign_update.mjs با کلید خصوصی انتشار. برای بررسی امضای Authenticode می‌توانید در ویندوز از Set-AuthenticodeSignature با گواهی ناشر خود استفاده کنید و پس از امضای فایل، اطلاعیه و هش‌ها را دوباره بسازید.

رابط موبایل/PWA و ورود گذرواژه‌ای آماده‌اند؛ استفادهٔ اصلی روی رایانهٔ ویندوز است. دسترسی گوشی دیگر نیازمند روشن‌بودن رایانه و تنظیم HTTPS و گذرواژه است؛ راهنما در desktop/REMOTE-ACCESS.md قرار دارد. داده‌های خصوصی API در Service Worker کش نمی‌شوند.

نسخهٔ ۰٫۴٫۲: پنجرهٔ مستقل WebView2 روی ویندوز؛ نیازمند Microsoft WebView2 Evergreen Runtime. در نبود Runtime و وجود Edge، پنجرهٔ جداگانهٔ Edge App استفاده می‌شود؛ صفحهٔ اصلی در فایرفاکس باز نمی‌شود. لینک خبرهای خارجی همچنان در مرورگر پیش‌فرض باز می‌شوند. بخش تاریخچه، بازهٔ سه‌سالهٔ قابل تنظیم و دریافت صفحه‌به‌صفحهٔ آرشیو گاردین با کلید رسمی دارد؛ بانک کامل خبرهای تمام ناشران از پیش همراه برنامه نیست.

ترجمهٔ فارسی خبرهای خارجی در کارت خبر کنار متن اصلی نمایش داده می‌شود؛ کلید Microsoft Translator را متصل کنید. ترجمهٔ خودکار تا ۱۰ خبر در هر جمع‌آوری و دریافت دستی ۱۰ خبر اخیر در تنظیم ترجمه موجود است. نوار قرمز عریض فقط خبرهای دارای واژگان نظامی را تا ۵۰ عنوان نشان می‌دهد؛ فیلتر واژه‌ای ممکن است خطا کند.

ایران اینترنشنال در فهرست منابع قرار دارد؛ هنگام افزودن، فید یا دادهٔ عمومی خبر بررسی می‌شود. دسترسی زندهٔ سایت در محیط ساخت به علت پاسخ ۴۰۳ پراکسی تأیید نشده است.


### اصلاحات ۰٫۴٫۲

- زوم نقشه با چرخ موس فعال است.
- دکمهٔ «ترجمه به فارسی» مستقیماً روی خبرهای خارجی قرار دارد و متن اصلی حفظ می‌شود. ترجمهٔ داخل برنامه به کلید رسمی Microsoft Translator در تنظیمات نیاز دارد.
- افزودن منبع، علاوه بر RSS و Atom، دادهٔ عمومی JSON-LD از نوع NewsArticle/Article و صفحه‌های خبری همان ناشر را می‌خواند؛ در هر دریافت حداکثر ۶ صفحهٔ مقاله بررسی می‌شود. فقط متن، زمان و رسانهٔ منتشرشده توسط ناشر ذخیره می‌شود؛ صفحه‌های نیازمند ورود، دسترسی محدود یا بدون دادهٔ ساختاریافته ممکن است قابل دریافت نباشند.
- حالت «فقط ذخیرهٔ پیوند سایت» برای سایت‌های بدون فید قابل خواندن اضافه شده است. این حالت دریافت خبر ندارد و در فهرست نیز همین وضعیت را نشان می‌دهد.
- افزودن ایران اینترنشنال اکنون دسترسی عمومی سایت را روی دستگاه شما بررسی می‌کند. آزمایش زندهٔ آن در محیط ساخت به علت پاسخ ۴۰۳ پراکسی ممکن نشده؛ اتصال موفق این سایت تضمین نشده است.


### دریافت اجتماعی بدون کلید — ۰٫۵٫۰

در «حساب‌های متصل» بخش «دریافت بدون کلید API» در بالای صفحه قرار دارد:

- تلگرام: نام یا لینک کانال عمومی؛ پیش‌نمایش وب `https://t.me/s/CHANNEL` خوانده می‌شود. ربات، توکن، شماره تلفن و ورود لازم نیست. حداکثر ۴۰ پست متنی موجود در پاسخ عمومی هر بار بررسی می‌شود؛ تاریخ، تصویر و ویدیوی واقعی در صورت انتشار عمومی حفظ می‌شوند. تاریخچهٔ کامل، چت‌ها و کانال خصوصی پوشش داده نمی‌شوند.
- YouTube: شناسهٔ کانال UC…، لینک کانال یا @handle؛ عنوان، توضیح و تصویر از فید عمومی ناشر دریافت می‌شود. شناسایی @handle به فرادادهٔ عمومی صفحه بستگی دارد؛ در صورت شکست، شناسهٔ UC… را وارد کنید. فایل ویدیو دریافت نمی‌شود.
- Mastodon: لینک پروفایل؛ RSS عمومی همان سرور خوانده می‌شود.
- Bluesky: نام عمومی حساب؛ همان اتصال عمومی موجود، بدون کلید و ورود، از این بخش نیز قابل افزودن است.

فقط بعد از پاسخ معتبر، اتصال ثبت می‌شود. پست‌های تلگرام هنگام ثبت وارد بانک محلی می‌شوند و سپس همراه جمع‌آوری دوره‌ای (هر ۱۵ دقیقه در حال اجرای برنامه) تازه می‌شوند؛ ذخیره‌شده‌ها حفظ می‌شوند. افزودن لینک `t.me` از فرم منابع نیز کانال عمومی را تشخیص می‌دهد. حذف منبع، اخبار بایگانی‌شدهٔ آن را حذف نمی‌کند.

این بخش ورود به حساب شخصی نیست. اینستاگرام، X، فیسبوک و لینکدین اتصال خودکار بدون کلید برای همهٔ صفحات در این نسخه ندارند؛ فرم‌های دارای توکن همچنان جداگانه موجودند. هیچ گذرواژه یا کوکی نشست درخواست نمی‌شود. دسترسی عمومی شبکه و دسترس‌بودن پیش‌نمایش یا فید لازم است. آزمون زندهٔ تلگرام از محیط ساخت به علت پاسخ ۴۰۳ پراکسی ممکن نشد؛ پارسر و چرخهٔ ثبت/جمع‌آوری با دادهٔ آزمایشی بررسی شده‌اند.


### گوگل و دریافت عمومی آزمایشی — ۰٫۶٫۰

روی خبر خارجی، «ترجمهٔ گوگل به فارسی · بدون کلید» ترجمه را از صفحهٔ عمومی وب Google Translate دریافت می‌کند. کلید، توکن یا ورود لازم نیست. این مسیر API رسمی Google Cloud نیست و ممکن است با تغییر صفحه، محدودیت تعداد درخواست یا درخواست تأیید مرورگر کار نکند. در آن صورت «بازکردن در گوگل» متن را در وب‌سایت خود گوگل آماده می‌کند؛ کپچا دور زده نمی‌شود. با درخواست شما، عنوان و حداکثر ۳۰۰۰ نویسهٔ نخست متن برای ترجمه فرستاده می‌شود. ترجمهٔ موفق در بانک محلی کش می‌شود؛ متن اصلی تغییر نمی‌کند. با تغییر متن یا عنوان ناشر، کش متناظر کنار گذاشته می‌شود. ترجمهٔ Microsoft با کلید همچنان جداگانه موجود است؛ ترجمهٔ خودکار تنظیم‌شده هنوز از Microsoft استفاده می‌کند.

در «حساب‌های متصل ← دریافت بدون کلید API»، Instagram و X با برچسب «آزمایشی» اضافه شده‌اند. نام حساب یا لینک مستقیم پست عمومی را وارد کنید. فقط محتوای عمومی قابل خواندن بدون ورود از صفحات یا نمایش عمومی خود پلتفرم جمع می‌شود: JSON عمومی و فرادادهٔ پست اینستاگرام، و صفحهٔ نمایش عمومی پست/تایم‌لاین X. تصاویر پروفایل و بیو به‌عنوان خبر ذخیره نمی‌شوند. پست‌های حساب دیگر، حساب خصوصی و صفحهٔ ورود اتصال موفق محسوب نمی‌شوند. برای اینستاگرام، حداکثر پنج پیوند پست معرفی‌شده در صفحهٔ عمومی نیز با تطبیق نویسنده بررسی می‌شوند. تاریخ نامعلوم صریحاً علامت می‌خورد؛ عکس یا ویدیوی تزئینی ساخته نمی‌شود.

عمومی‌بودن پیج تضمین نمی‌کند محتوایش بدون ورود قابل دریافت باشد. هیچ کوکی نشست، رمز، توکن یا کلید مشترک درخواست یا استخراج نمی‌شود. اگر نمایش عمومی در دسترس نباشد، خطای روشن نشان داده می‌شود و اتصال ثبت نمی‌شود. اتصال واقعی و زندهٔ Google، Instagram و X در محیط ساخت، به دلیل پاسخ ۴۰۳ پراکسی، تأیید نشده است. پارسرها، کش، محدودکردن دامنه، رد صفحهٔ ورود و چرخهٔ ثبت/جمع‌آوری با دادهٔ آزمایشی بررسی شده‌اند.
